# Aethel trip logo kit

Source artwork: `../aethel-trip-block-transparent.png` (generated in Figma, file cepXUjk9cr2OKEsnehvDFb). Every file here is that artwork recoloured and arranged, not redrawn.

- `aethel-trip-brand-sheet.png`: one-page guide (logo, colours, type, space, sizes, don'ts, Instagram).
- `logo/stacked/`: main logo, two lines. `-cream-orange` for dark backgrounds, `-navy-orange` for light ones, `-one-colour` files for single-colour use.
- `logo/horizontal/`: one-line version for wide spaces (headers, email signatures, banners).
- `logo/mark/`: the "At." mark for small spaces, icons and stamps.
- `logo/on-colour/`: previews on navy, cream, pale blue and orange.
- `instagram/`: 1080 x 1080 profile pictures A to D. Upload one; Instagram crops to a circle. `_preview-circle-crop.png` shows how each looks.
- `social/`: the same picture A at 400 px (WhatsApp, Facebook, YouTube) and 300 px (LinkedIn, X).

Colours: Night #0a1322, Deep blue #122e45, Steel #2d4e5f, Glow #c4eae7, Cream #fffaf1, Orange #e5623a.
Type: Unbounded ExtraBold (headlines, capitals), Onest (text).
All files are PNG with transparent backgrounds, except those on a colour. For print at large sizes, export the vector from the Figma file.
